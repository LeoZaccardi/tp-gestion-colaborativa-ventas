# TP Gestión Colaborativa de Ventas

## Materia

Organización Empresarial - Tecnicatura Universitaria en Programación - UTN.

## Escenario elegido

Escenario B: Análisis de Ventas de una Pequeña Empresa.

## Descripción del proyecto

Este proyecto consiste en analizar un conjunto de datos simulados de ventas comerciales para obtener indicadores básicos que ayuden a interpretar el desempeño de una pequeña empresa.

El análisis contempla:

- ventas totales;
- producto más vendido;
- ventas por mes;
- ventas por producto;
- generación de resultados y gráficos.

## Roles simulados

Debido a que el trabajo se realiza de manera individual, se simulan los roles propuestos en la consigna:

- P1 - Líder y Organizador: creación del repositorio, estructura inicial y README.
- P2 - Desarrollador Técnico: desarrollo del dataset, script y resultados.
- P3 - Revisor QA: revisión de documentación, seguridad y Pull Request.

## Trazabilidad con Jira

Cada commit del proyecto comienza con el identificador del issue correspondiente en Jira:

- GCV-1: Crear repositorio y estructura inicial.
- GCV-2: Desarrollar script de análisis de ventas.
- GCV-3: Revisar documentación, seguridad y Pull Request.
